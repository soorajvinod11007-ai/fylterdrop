# Admin Page Overrides

> **Route:** `/admin`
> **Applies with:** [MASTER.md](../MASTER.md)

## Layout

- Treat the admin interface as a task-focused operations tool, not a consumer-facing campaign page.
- Keep product management, inventory, images, and settings grouped into predictable panels with a persistent page hierarchy.
- Use compact spacing where it improves scanning, while retaining readable labels and clear section boundaries.
- Preserve the current access flow and existing admin actions.

## Interaction

- Make loading, success, validation, and failure states explicit.
- Keep destructive actions distinct and confirmed; preserve keyboard access and visible focus.
