# Categories Page Overrides

> **Route:** `/categories`
> **Applies with:** [MASTER.md](../MASTER.md)

## Layout

- Present categories as an image-led editorial index, with a clear page introduction and concise category descriptions.
- Use an asymmetric grid with consistent image framing and category labels anchored to the image edge.
- Preserve readable text contrast over photography using a restrained dark overlay rather than glass cards.

## Interaction

- Make the full category tile a single, clearly named link to its filtered shop view.
- Use subtle image movement only; preserve the tile bounds and visible focus treatment.
